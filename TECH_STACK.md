# AI Career Copilot

## Overview
AI Career Copilot is a full-stack AI-powered application that helps users analyze resumes, match them to relevant jobs, generate personalized learning roadmaps, and practice mock interviews.

## Tech Stack

### Frontend
- Next.js 15
- React 19
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Radix UI
- lucide-react
- react-markdown
- next-themes

### Backend
- FastAPI
- Python
- SQLAlchemy
- SQLite (development)
- JWT authentication

### AI / ML
- Ollama + Llama 3.1
- PyMuPDF for PDF text extraction
- FAISS for semantic matching
- Embedding-based job matching
- Planned agentic interview system with LangGraph

### Dev Tools
- Docker Compose
- Node.js / npm
- Python virtual environment

## Project Goals
- Parse resumes into structured data
- Match users to relevant jobs semantically
- Generate skill-gap roadmaps
- Provide interactive interview preparation
